모두의 마라톤 개인정보처리방침

최종 업데이트: 2026-10-19 · 개발자: 모두의시리즈(Moduseries) · 문의: jasi798@gmail.com

본 방침은 모바일 게임 모두의 마라톤(패키지명 com.moduseries.marathon, 이하 "본 앱")의 개인정보 처리에 관한 내용을 설명합니다.

1. 수집하는 정보

본 앱은 이름·이메일·전화번호·위치 등 개인을 식별할 수 있는 정보를 수집하지 않습니다. 회원가입이나 로그인이 없습니다.

게임 진행 데이터(코인, 기록, 해금 코스·곡, 업적, 설정, 완주 기록증에 입력한 이름 등)는 이용자 기기 내부에만 저장되며 개발자의 서버로 전송되지 않습니다.

2. 광고 및 분석

본 앱은 광고를 표시하지 않으며, 광고 식별자나 이용 통계를 수집하는 분석 도구를 사용하지 않습니다.

3. 인터넷 연결

본 앱은 최신 게임 버전을 불러오기 위해 실행 시 GitHub Pages(seungiljang.github.io)에서 게임 파일을 내려받습니다. 이 과정에서 일반적인 웹 요청과 마찬가지로 호스팅 제공자(GitHub)가 IP 주소 등 접속 기록을 처리할 수 있으며, 이는 GitHub의 개인정보처리방침을 따릅니다:
GitHub 개인정보처리방침

4. 공유 기능

완주 기록증 공유는 이용자가 직접 선택한 앱(메신저 등)으로 이미지를 전달하는 기기 기능을 사용합니다. 본 앱 개발자는 공유된 내용을 받거나 저장하지 않습니다.

5. 정보의 공유·판매

본 앱 개발자는 이용자 정보를 수집하지 않으므로 제3자에게 제공하거나 판매하지 않습니다.

6. 아동 보호

본 앱은 만 14세 미만 아동을 포함한 누구의 개인정보도 수집하지 않습니다.

7. 데이터 삭제

게임 안의 설정 → 데이터 초기화를 누르거나 앱을 삭제하면 기기에 저장된 모든 게임 데이터가 제거됩니다.

8. 변경

본 방침은 변경될 수 있으며, 변경 시 본 페이지에 업데이트됩니다.
